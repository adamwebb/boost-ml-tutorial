Tidymodels for machine learning in R

Author

Adam Webb adam.webb@leicester.ac.uk

In this section we will look at tidymodels.Tidymodels represents a complete suite of packages designed to simplify machine learning in R. We will focus on the following core components:

  • rsample: split datasets into test / training / validation. Also includes tools for cross validation

  • recipes: define a series of steps to pre-process data parsnip: easy way to try out lots of different models

  • tune: optimise model hyperparameters (also dials which helps with tuning)

  • workflows: bring together sampling, recipes, models and tuning into a single workflow

  • yardstick: check the performance of models broom: extract important information from models

  • There are also various additional packages, more information can be found at https://www.tidymodels.org/packages/

The easiest way to load these packages is to just call:

library(tidymodels)

Creating testing and training datasets

In machine learning we need a training dataset and a test dataset. We build our models with the training data, then see how well it predicts outcomes in a new, unseen, test dataset.

Ideally, our test dataset would be entirely new. Otherwise, we can split our main dataset. A 70/30 or 80/20 split would be ideal.

Tidymodels provides the rsample package which assists. with this.

Cross validation:

Split the data into five blocks (1-5) then:

train on 1,2,3 and 5, test on 5 train on 1,2,3,5, test on 4 train on 1,2,4,5, test on 3 train on 1,3,4,5, test on 2 train on 2,3,4,5, test on 1

If we want to do cross validation, we can use rsample again, this time creating cross-validation folds from the training data only:

v = number of folds repeats - number of times to repea this strata - ensure equal proportions of the strata. variable in each fold.

In the example we have 5 sets of 5 folds (so 25 in total)

This creates a 5-fold cross validation set, then repeats the process 5 times. A set like this can be used when tuning more complex models such as LASSO regression models and random forest models. Various paramters are systematically tested - performance is estimated from the multiple cross validation sets.

Ultimately this gives us 25 ROC-AUC scores - from this we can estimate both ROC-AUC and a confidence interval.

Recipes - processing data

The recipes package gives us a large number of data processing steps to help prepare data for modelling. First we define the recipe using recipe(). To this obejct we add a number of processing steps using functions beginning with step_.

Then we prep() the recipe. This step trains the recipe based on the training data.

For example: a recipe containing step_corr() is passed to prep(). prep() feeds the training data to the recipe. step_corr() removes correlating variables. The prepared recipe contains a list of variables to be removed.

bake() is used to apply those intructions to a dataset. By default the training set is used, but that dataset can be replaced by any other (e.g. a test dataset) by setting the new_data argument. The result is a dataset which has been processed using the pre-trained recipe. In our example, correlating variables identified in training dataset are removed from the test dataset.

A full list of step_ functions can be found at https://recipes.tidymodels.org/reference/index.html.
